Pantau OBS di HP

  1. Di OBS buka Tools > WebSocket Server Settings
  2. Centang Enable WebSocket server (OBS 28 ke atas)
  3. Isi password di bawah kalau OBS memakainya

Sambungkan HP

  1. Buka aplikasi Gatito: Stream Tool di HP
  2. Tekan Scan QR, arahkan kamera ke kode ini

Port yang sebaiknya dihindari

Port ini biasanya sudah dipakai program lain. Kalau dimasukkan, Gatito menolaknya.

Port 3000 (bawaan) juga dipakai ChatLivestream Labs dan banyak tool developer. Kalau 3000 sedang terpakai saat Gatito dibuka, Gatito otomatis pindah ke port kosong berikutnya dan memberi tahu kamu. Supaya HP tidak perlu scan ulang, simpan port tetap yang jarang dipakai, misalnya 3456 atau 4600.
